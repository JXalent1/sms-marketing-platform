{# A5 — rename, archive and unarchive a list, where he picks an audience. Not a new page and not a nav entry. The composer's dropdown is the whole of the "use an existing audience" tab since 5i, so every test upload became a permanent entry in it and there was no way for the client to tidy that up — ten one- and two-member lists were deleted by hand on the live box on 2026-09-04. This is the affordance the picker was missing, and it belongs beside the picker. The numbers come from /api/lists/manage, which is built from the same read `list_summaries()` serves the dropdown from, so a row here and an option there cannot report different counts for the same list. Archived rows are the only difference between the two payloads. The picker states "archived" by absence; this panel states it with a badge and an Unarchive button — one predicate behind both, `contact_service.is_archived()`. A .html partial rather than a file under app/static/, like every other composer partial: Tailwind's content scan is `./app/templates/**/*.html`, so the class strings built in JS below are compiled into app.css. #}
