{# Composer behaviour. Included by campaigns.html inside {% block scripts %}. A .html partial rather than a file under app/static/ for one concrete reason: Tailwind's content scan is `./app/templates/**/*.html`, so the class strings in the lookup tables below are compiled into app.css. The same strings in a .js file would be purged and the checklist would render unstyled. Two rules this file keeps: - Class names are literals in a lookup table, never concatenated from a value the API returned. A colour token arriving as "s9" picks the fallback; it never produces `text-s9`, which would silently be no class at all. - Every money figure comes from the API. Nothing here multiplies a rate. #}
