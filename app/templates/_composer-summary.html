{# The composer's summary panel — the "This send" box, and the one function that writes every row of it. Split out of `_composer-script.html` in session 5m, which put that file at 538 lines against a 500-line rule. The boundary is not arbitrary: this is the panel's *whole* writer, and the session's finding was that the panel had three of them. A partial containing exactly one function that may touch those rows is the shape of the fix as much as the code is. Included **before** `_composer-script.html` so that `panelSequence` and `EMPTY_SUMMARY` — top-level `const`s, which live in the shared global lexical environment and are in their temporal dead zone until this block runs — are initialised before anything can reach them. `setMode('upload')` at the bottom of `_composer-upload.html` calls `paintSummary()` synchronously at parse time, and that is the call this ordering exists for. It uses `el()` and `money()` from `_composer-script.html`, and only ever from inside a function body, so those resolve at call time and the order is safe in that direction too. A .html partial rather than a file under app/static/ for its siblings' reason — Tailwind's content scan is `./app/templates/**/*.html`. This file happens to build no class names today; keeping it here means it can, and means the composer is one set of files rather than one set and an exception. #}
