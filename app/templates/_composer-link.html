{# The {link} merge tag's own behaviour. Included by campaigns.html last. Its own partial for the reason the other two are: the 500-line rule, and Tailwind's content scan reaching class names built in JS. `_composer-script` was at 493 lines before this session. `linkTarget()` is a function declaration, so it is hoisted to the global scope and callable from the earlier partial's fetch bodies. Those all run from events or from an awaited load, long after both scripts have parsed — the same arrangement `_composer-upload.html` already relies on in reverse. One rule here, and it is the whole of 5f A3: **this file decides nothing.** Whether a link can be minted, and what to say when it cannot, comes from the server — /api/campaigns/preview reports `link_available`, and the pre-flight `short_link` row carries the sentence. A screen that worked either out for itself would offer the tag on a box with no domain configured, which is a refusal arriving at send time instead of compose time. #}
