Your plan
How segments are counted

Messages are billed in segments, not messages. How many segments a message costs depends on its length and which characters it contains.

Standard text

Letters, digits and basic punctuation (GSM-7).

  • 160 characters = 1 segment
  • Longer messages split every 153 characters
With an emoji or special character

One emoji switches the whole message to Unicode (UCS-2).

  • 70 characters = 1 segment
  • Longer messages split every 67 characters
Example
A 300-character message is 2 segments as plain text and 5 segments with a single emoji added.

Usage reflects the actual segment count reported for each message, so it always matches what was really sent.
